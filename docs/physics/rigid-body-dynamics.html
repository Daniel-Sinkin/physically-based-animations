Rigid Body Dynamics

Linear and angular update model used in the fixed-step simulation loop.

State Variables

For each body, the solver tracks:

  • Position \(\mathbf{x}\), velocity \(\mathbf{v}\), inverse mass \(m^{-1}\)
  • Orientation quaternion \(q\), angular velocity \(\boldsymbol{\omega}\)
  • Body-space inverse inertia \(\mathbf{I}_{body}^{-1}\)
  • World-space inverse inertia \(\mathbf{I}_{world}^{-1}\)
  • Force and torque accumulators

Linear and Angular Integration

\[ \mathbf{a} = \mathbf{F}\,m^{-1}, \qquad \mathbf{v}_{t+\Delta t} = \mathbf{v}_{t} + \mathbf{a}\,\Delta t \]
\[ \boldsymbol{\alpha} = \mathbf{I}_{world}^{-1}\,\boldsymbol{\tau}, \qquad \boldsymbol{\omega}_{t+\Delta t} = \boldsymbol{\omega}_{t} + \boldsymbol{\alpha}\,\Delta t \]
\[ \mathbf{x}_{t+\Delta t} = \mathbf{x}_{t} + \mathbf{v}_{t+\Delta t}\,\Delta t \]

Orientation update is quaternion-based:

\[ q_{t+\Delta t} = \operatorname{normalize}\left(q_t + \frac{\Delta t}{2}\,\Omega(\boldsymbol{\omega})\,q_t\right) \]

Quaternion composition is order-dependent (non-commutative), so composed rotations use an explicit order:

\[ q_{total} = q_2 q_1 \neq q_1 q_2 \]

See Math Background / Quaternions for the multiplication table and algebra details.

Inertia Tensor Mapping

\[ \mathbf{I}_{world}^{-1} = \mathbf{R}(q)\,\mathbf{I}_{body}^{-1}\,\mathbf{R}(q)^T \]

Velocity at a Contact Point

\[ \mathbf{v}_a = \mathbf{v}_{cm} + \boldsymbol{\omega}\times(\mathbf{p}-\mathbf{x}_{cm}) \]
