Contact Resolution

Sequential impulses with friction, warm-starting, and position correction.

Normal Impulse Solve

The solver computes contact impulses iteratively. For each contact, relative normal velocity \(v_{\text{rel}}\) and effective mass \(k\) are used to solve the incremental normal impulse:

\[ \Delta\lambda_n = -\frac{(1+\epsilon)\,v_{\text{rel}} + b}{k} \]

\(\lambda_n\) is accumulated and clamped non-negative, then impulse \(\mathbf{J}_n = \Delta\lambda_n\,\mathbf{n}\) is applied to linear and angular velocities.

Friction Impulse

Tangential slip is projected from relative contact velocity. The tangent impulse accumulator is clamped with a Coulomb bound:

\[ |\lambda_t| \le \mu\,\lambda_n \]

This produces \(\mathbf{J}_t = \Delta\lambda_t\,\hat{\mathbf{t}}\), applied with the same angular coupling terms as normal impulses.

Warm Starting and Position Solve

Cached \((\lambda_n,\lambda_t,\hat{\mathbf{t}})\) values are pulled at frame start to accelerate convergence. After the velocity loop, positional correction runs for a small number of iterations to reduce residual penetration.

\[ \mathbf{c} = \frac{\beta\,\max(0, p - p_{\text{tol}})}{m_a^{-1}+m_b^{-1}}\,\mathbf{n} \]

with \(p\) penetration depth, \(p_{\text{tol}}\) tolerance, and \(\beta\) correction factor.

Contact data is transient and lives in contact_arena, cleared once per physics step before regeneration. 

// sequential impulses (conceptual shape)
warm_start_contact(contact, bodies, dt);
for (int iter = 0; iter < velocity_iterations; ++iter) {
  solve_velocity_constraints(contact_span, bodies, dt);
}
for (int iter = 0; iter < position_iterations; ++iter) {
  solve_position_constraints(contact_span, bodies, dt);
}

Validation and Diagnostics

  • Broadphase and contact counts are exposed in the Physics Debug UI.
  • Kinetic energy history can be tracked over time for stability inspection.
  • Headless runs provide average/max step-time summaries for tuning solver iterations.
