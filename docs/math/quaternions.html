Quaternions and Rotation Algebra

Quaternion algebra for orientation state, stable rotation composition, and vector rotation.

From Complex Numbers to Quaternions

A quaternion is \[ q = w + x\mathbf{i} + y\mathbf{j} + z\mathbf{k} \] with one real part and three imaginary components.

The dimension chain of normed division algebras is: \[ \mathbb{R} \;\subset\; \mathbb{C} \;\subset\; \mathbb{H} \;\subset\; \mathbb{O} \]

  • \(\mathbb{R}\): ordered, commutative, associative field
  • \(\mathbb{C}\) (2D): still commutative/associative, but no order compatible with multiplication
  • \(\mathbb{H}\) (4D): associative, but multiplication is non-commutative
  • \(\mathbb{O}\) (8D octonions): non-associative (but alternative)

Quaternion Basis Rules

\[ \mathbf{i}^2 = \mathbf{j}^2 = \mathbf{k}^2 = \mathbf{i}\mathbf{j}\mathbf{k} = -1 \]
\[ \mathbf{i}\mathbf{j}=\mathbf{k},\; \mathbf{j}\mathbf{k}=\mathbf{i},\; \mathbf{k}\mathbf{i}=\mathbf{j},\; \mathbf{j}\mathbf{i}=-\mathbf{k},\; \mathbf{k}\mathbf{j}=-\mathbf{i},\; \mathbf{i}\mathbf{k}=-\mathbf{j} \]

Quaternion Multiplication Table

* 1 i j k
1 1 i j k
i i -1 k -j
j j -k -1 i
k k j -i -1

Rotations With Unit Quaternions

For rotation angle \(\theta\) about unit axis \(\hat{\mathbf{n}}\):

\[ q = \left(\cos\frac{\theta}{2},\; \hat{\mathbf{n}}\sin\frac{\theta}{2}\right), \qquad \|q\|=1 \]

Rotate vector \(\mathbf{v}\) by treating it as a pure quaternion \((0,\mathbf{v})\):

\[ \mathbf{v}' = q\,\mathbf{v}\,q^{-1} \]

Composition follows multiplication order: \[ q_{total}=q_2 q_1 \] so applying \(q_1\) then \(q_2\) is not the same as swapping them.
