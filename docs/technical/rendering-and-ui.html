Rendering and UI

Viewport render passes, shader/resource setup, and editor interaction workflows.

Viewport Render Passes

The viewport render path is executed in ordered passes:

  1. Environment dome
  2. Grid
  3. Scene objects
  4. Selection outline via stencil
  5. Physics debug overlays (optional)
  6. Editor pivot marker

Implemented in src/pba/gfx/gfx_viewport.cpp.

// render entrypoint shape
const auto aspect = viewport_fbo.aspect_ratio();
const auto& cam = engine_context->simulation.world.editor_state().camera();
const auto view_matrix = cam.view_matrix();
const auto proj_matrix = cam.proj_matrix(aspect);

Camera Transform Model

The editor camera is orbit-style and stored as pivot + spherical angles + distance. Position is derived each frame from \((\text{yaw}, \text{pitch}, \text{distance})\):

\[ \mathbf{p}_{\text{cam}} = \mathbf{p}_{\text{pivot}} + \begin{pmatrix} d\cos(\text{pitch})\cos(\text{yaw}) \\ d\cos(\text{pitch})\sin(\text{yaw}) \\ d\sin(\text{pitch}) \end{pmatrix} \]

View/projection transforms are then:

\[ \mathbf{V} = \operatorname{lookAt} \left( \mathbf{p}_{\text{cam}}, \mathbf{p}_{\text{pivot}}, \mathbf{\hat{z}} \right), \qquad \mathbf{P} = \operatorname{perspective} \left( \text{fov}_y,\, \text{aspect},\, z_{\text{near}},\, z_{\text{far}} \right) \]

Source mapping:

  • src/pba/scene/camera.cpp: position(), view_matrix(), proj_matrix()
  • src/pba/core/constants.hpp: camera defaults and limits

Picking and Unprojection

Mouse coordinates inside the viewport are converted to NDC, then unprojected through inverse clip transform to produce a world-space ray:

\[ (x_{\text{ndc}}, y_{\text{ndc}}) = \left( 2\frac{x_{\text{local}}}{w}-1,\; 1-2\frac{y_{\text{local}}}{h} \right) \]
\[ \mathbf{C2W} = (\mathbf{P}\mathbf{V})^{-1},\qquad \mathbf{p}_{\text{near}}=\mathbf{C2W}(x_{\text{ndc}},y_{\text{ndc}},-1,1),\qquad \mathbf{p}_{\text{far}}=\mathbf{C2W}(x_{\text{ndc}},y_{\text{ndc}},1,1) \]

The normalized ray direction is \(\mathbf{\hat{d}}=\operatorname{normalize}(\mathbf{p}_{\text{far}}-\mathbf{p}_{\text{near}})\).

  • src/pba/gfx/raycast.cpp: ray_from_imgui_rect()
  • src/pba/core/geometry.cpp: clip_to_world()
// unprojection path (conceptual shape)
const auto c2w = clip_to_world(camera_proj_matrix, camera_view_matrix);
const auto near_w = c2w.unproject_ndc(x_ndc, y_ndc, -1.0f);
const auto far_w  = c2w.unproject_ndc(x_ndc, y_ndc, +1.0f);
Ray ray{near_w, normalize(far_w - near_w)};

Camera Interaction Dynamics

Orbit, pan, and zoom are mapped directly to camera parameters:

  • Zoom: exponential distance scaling with wheel input and clamped range
  • Orbit: yaw/pitch deltas from pointer motion with pitch clamp
  • Pan: pixel delta converted to world offset from camera right/up basis
  • src/pba/gfx/gfx_interaction.cpp
  • src/pba/scene/camera.cpp: pan_offset_world(), right(), up()
// interaction update shape
cam.distance *= exp(-wheel * zoom_speed);
cam.yaw += -dx * sensitivity;
cam.pitch = clamp(cam.pitch + dy * sensitivity, -pitch_limit, pitch_limit);
cam.pivot += cam.pan_offset_world(dx, dy, viewport_height_px) * pan_sensitivity;

Environment Lighting

The renderer samples an equirectangular environment texture for diffuse/specular lighting. If no HDRI/JPG asset is present, a procedural fallback map is generated at startup.

UI Tooling

Tool windows are built with ImGui and include Scene selection, Render controls, Physics Debug, Inspector, and Terminal panels.

  • src/pba/ui/ui.cpp
  • src/pba/gfx/gfx_context.cpp

The runtime supports hot scene reload, pause/step controls, and debug window reveal.

Interaction Model

  • Single and additive selection (click and shift-click)
  • Viewport box-select with optional through-depth mode
  • Multi-object grab/move with axis constraints
  • Camera orbit, pan, and zoom controls
