References and Further Reading

Theory, implementation, and tooling references used by this project documentation.

Physics | Math | C++ Performance Talks | Rendering | Tooling

Physics and Simulation

  • Erin Catto (GDC 2005), Iterative Dynamics with Temporal Coherence Iterative impulses, contact constraints, and warm-start intuition.
  • David Baraff, Physically Based Modeling (SIGGRAPH notes) Core rigid-body dynamics and constraint derivations.
  • Christer Ericson, Real-Time Collision Detection Broadphase/narrowphase algorithms and geometric robustness.
  • Glenn Fiedler, Fix Your Timestep! Fixed-step loop design and simulation stability tradeoffs.
  • Box2D Practical reference implementation for solver behavior and validation.

Math and Rotations

  • Understanding Quaternions (3D Game Engine Programming) Quaternion representation and rotation composition walkthrough.

C++ Performance Talks

  • Vittorio Romeo (CppCon 2025), More Speed & Simplicity: Practical Data-Oriented Design in C++ Data-first architecture, cache-aware layout, staged updates, and pragmatic OOP + DoD blending.
  • Scott Meyers (CppCon 2014), CPU Caches and Why You Care Memory hierarchy and cache-line behavior behind real-world performance bottlenecks.
  • Jonathan Mueller (CppCon 2018), Cache-friendly C++ Practical cache-aware data and access-pattern design in modern C++.

Rendering and Graphics

  • Physically Based Rendering: From Theory to Implementation (4th edition) Foundational physically based rendering techniques.
  • Khronos OpenGL Reference Pages Authoritative OpenGL API behavior and usage details.

Implementation and Tooling

  • OpenGL (Khronos reference pages) Core graphics API used for rendering.
  • Dear ImGui Immediate-mode editor/debug UI framework.
  • nlohmann/json JSON parsing/serialization for config and UI theme data.
  • tinyobjloader OBJ mesh loader dependency (included in build dependencies).
  • tinygltf glTF reader/writer used by asset loading paths.
  • GLM Vector/matrix/quaternion math library used across simulation and rendering.
  • GLFW Window/context/input management.
  • GLAD OpenGL function loader.
  • stb (stb_image/stb_image_write) Image loading and image write helpers.
  • Microsoft Guidelines Support Library (GSL) Utility types and safer interface patterns in modern C++.
  • Doxygen Autogenerated C++ API reference and source-linked documentation.
  • KaTeX Client-side math rendering for equations in docs pages.
  • highlight.js Syntax highlighting for code snippets in hand-written docs.
