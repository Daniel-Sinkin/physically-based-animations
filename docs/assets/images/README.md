# Images

Documentation image assets used by the GitHub Pages docs.

## physics

- `physics/AxisAlignedStandardBox.svg`: Axis-aligned standard box notation with center and half-extents.

### physics/bounding

- `physics/bounding/AABB.png`: Axis-aligned bounding box reference image.
- `physics/bounding/OBB.png`: Oriented bounding box reference image.
- `physics/bounding/SphereBounding.png`: Bounding-sphere reference image.
- `physics/bounding/kOBB.png`: k-OBB reference image.

## intersection-checks

- `intersection-checks/CubeBase.png`: Base unit cube in local space.
- `intersection-checks/CubeScaled.png`: Cube after non-uniform scaling.
- `intersection-checks/CubeFinal.png`: Cube after full transform (scaled + rotated).
- `intersection-checks/CubeFinalAABB.png`: AABB built around transformed cube.
- `intersection-checks/FinalTrafoSingle.png`: Single-object transformed reference frame.
- `intersection-checks/2Cube.png`: Two transformed cubes before AABB overlays.
- `intersection-checks/2CubeAABB.png`: Two transformed cubes with AABB overlays.
- `intersection-checks/2CubeAABBIntersection.png`: Broadphase AABB overlap volume.
- `intersection-checks/2CubeAABBIntersectionCloseup.png`: Close-up of overlap region.
- `intersection-checks/2CubeAABBIntersectionCloseupSide.png`: Side-view close-up of overlap depth.
- `intersection-checks/2CubeAABBIntersectionCloseupTopdown.png`: Top-down close-up of overlap region.
- `intersection-checks/2CubeIntersectionSAT.png`: SAT visualization for the intersecting case.
- `intersection-checks/2CubeIntersectionSAT_Separator.png`: SAT separating-axis visualization.
- `intersection-checks/2CubeIntersectionSAT_noIntersection.png`: SAT no-intersection case visualization.
