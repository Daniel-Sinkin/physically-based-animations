Parallel Index Traversal

Shared wrapper for parallel/serial index kernels.

A thin parallel_for_index wrapper is used for index-based loops in physics build/update stages. It keeps call sites uniform and falls back to a serial loop when OpenMP is not enabled. 

// src/pba/core/parallel_for.hpp
template <class Fn>
inline auto parallel_for_index(usize count, Fn&& fn) -> void {
#if defined(DS_PBA_USE_OPENMP)
  #pragma omp parallel for schedule(static)
  for (i64 i = 0; i < static_cast<i64>(count); ++i) fn(static_cast<usize>(i));
#else
  for (auto i = 0zu; i < count; ++i) fn(i);
#endif
}

Used in src/pba/physics/collision.cpp, src/pba/physics/solver.cpp, and src/pba/physics/physics_context.cpp.
